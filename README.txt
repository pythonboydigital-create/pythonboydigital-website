PUBLISH ON GITHUB PAGES
1. Download and extract this ZIP on your phone/computer.
2. Open https://github.com/pythonboydigital-create/pythonboydigital-website
3. Tap Add file > Upload files. Upload the CONTENTS of the extracted folder (index.html, logo.jpg, robots.txt, sitemap.xml) into the repository root. Do not upload only the ZIP.
4. Commit changes to the main branch.
5. Open repository Settings > Pages.
6. Under Build and deployment select Deploy from a branch.
7. Choose Branch: main and Folder: /(root), then Save.
8. Wait for GitHub Pages deployment. Expected URL:
   https://pythonboydigital-create.github.io/pythonboydigital-website/

GOOGLE SEARCH
1. Open https://search.google.com/search-console/
2. Add a URL-prefix property using the exact live URL above.
3. Complete the ownership verification requested by Google.
4. Inspect the homepage URL and click Request Indexing.
5. Submit sitemap.xml in the Sitemaps section.
